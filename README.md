# Smart Expense Tracker Web Application

A modern web-based application to track daily income and expenses with a clean UI, secure authentication, and insightful reports.

## Features

###Authentication
User Registration & Login
Secure password hashing using Werkzeug
Session-based authentication

###Expense Management
Add Income & Expenses
Edit and Delete transactions
Search and filter transactions

###Reports & Visualization
Monthly financial reports
Doughnut chart for Income vs Expense
Real-time balance calculation

###Export
Download monthly reports as PDF
